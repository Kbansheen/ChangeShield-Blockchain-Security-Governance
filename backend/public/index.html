SYSTEM DESIGN

How ChangeShield works

A hybrid architecture combines blockchain authorization with controlled off-chain configuration management.

01 · ADMIN A Creates a change proposal
↓
02 · EXPRESS BACKEND Validates input and calculates configuration hash
↓
03 · CHANGESHIELD SMART CONTRACT Stores proposal, approval, rejection, expiry and execution events
↓
04 · ADMIN B Independently approves or rejects the proposal
↓
05 · BACKEND EXECUTOR Verifies the approved proposal and executes it on-chain
↓
06 · CONFIGURATION FILE Updated only after confirmed blockchain execution

Security controls

  • Two-person approval for critical changes
  • Prevention of self-approval
  • Configuration hash verification
  • Execution restricted to the authorized executor
  • Proposal deadlines and automatic expiry
  • Protection against duplicate execution
  • Blockchain event-based audit history
